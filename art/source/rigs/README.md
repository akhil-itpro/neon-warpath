# ROOK separated-parts master

`rook_parts.png` is the original built-in imagegen atlas from 2026-11-15. The game uses the brighter revision `rook_parts_bright.png`, generated from that reference. Its exact prompt is in `rook_parts_bright_prompt.txt`. Both originals have alpha and are kept intact.

VIPER, TITAN, SERRIK and QUILL each have their own eight-piece atlas and matching prompt in this folder. Their runtime parts use the same joint layout, with barrel locations measured separately.

Rebuild all five with `python -B tools/process_operator_rigs.py`, or add an operator ID to rebuild one. The script hardens alpha, extracts each cell's connected opaque piece, scales the pieces to game pixels, applies the existing sprite contrast lift and registers the textures.

Part origins, leg lengths, foot targets and the barrel point are in `src/data/rigs.ts`. Rendering/animation is in `src/systems/CharacterRig.ts`; Player retains physics and combat. Missing parts fall back to the intact original sheet. Title uses the same puppet.

Verification: `npm.cmd run smoke -- rook-rig`. The final eight screenshots are a stable run-cycle review rendered by the real rig. Earlier screenshots cover live movement/aim/poses/hurt/death/retry. `tools/preview_rook_rig.py` makes the review GIF and contact sheet. These are previews, not evidence of normal-health campaign completion.

## Exact built-in generation prompt

Create a production sprite parts atlas for an ORIGINAL 2D side scrolling pixel art action game, character ROOK: dark short hair, muscular male special forces operator, charcoal navy tactical armor, teal shoulder stripe, fingerless gloves, compact steel pistol. Strict SIDE VIEW FACING RIGHT. Detailed 16-bit pixel art, clean hard edges, 24-color steel/teal palette, near-black outline, subtle cool cyan edge highlights. Transparent background. This is NOT an animation sheet: eight SEPARATE DISCONNECTED puppet pieces, one in each cell of a perfectly regular 4 columns x 2 rows atlas on a 1536x1024 transparent canvas. Every cell contains EXACTLY ONE isolated piece centered with huge clear margins. No assembled full body, no labels, no shadows, no grid. ORDER: top row cell1 HEAD with neck, upright facing right; cell2 TORSO with armored chest waist and belt, NO HEAD NO ARMS NO LEGS; cell3 RIGHT AIMING ARM AND PISTOL, one connected piece from rounded shoulder on left through nearly horizontal bent forearm to pistol pointing RIGHT at far right, barrel horizontal, arm overall horizontal; cell4 FAR SUPPORT ARM, a bent arm horizontal pointing right with glove, NO GUN. Bottom row cell1 FRONT THIGH from rounded hip at top to rounded knee at bottom, hanging straight down; cell2 FRONT SHIN WITH BOOT, knee at top boot at bottom, boot toe pointing right; cell3 FAR THIGH same size darker shading; cell4 FAR SHIN WITH BOOT same size darker shading. All pieces belong to the SAME character and SAME size scale as if assembled into a 320px high character: head approximately 70px high, torso 130px high, thighs 85px high, shins with boots 90px high, gun arm 170px long. Opaque armor pieces with complete overlapping ends so rotation never makes holes. No gore. Do not draw extra disconnected details. Essential: exactly eight pieces in the requested grid, consistent proportions, generous transparent padding.
