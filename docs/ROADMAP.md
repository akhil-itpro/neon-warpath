# Roadmap

Honest framing: "AAA" is a budget tier (hundreds of people). The realistic target for one person plus AI is a **top-tier indie**: small scope, extreme polish. Polish and game feel sell indie action games, not content volume.

## Milestone 0 — Playable campaign (in progress)
See `docs/HANDOFF.md` for exact status. Exit: all 3 stages and bosses verified by smoke test and a human playthrough.

## Milestone 1 — Vertical slice worth showing (stage 1 only, perfect)
- Real art for gangsters and operators VIPER/TITAN; boss death and player death animations.
- Balance and feel pass with 5 outside playtesters (watch them play, do not explain anything).
- Options menu (volume, screen shake, flashes), key rebinding, gamepad prompts.
- Free web demo on itch.io; capture a 30-second trailer and GIFs.

## Milestone 2 — Content
- Stages 4-6 (Syndicate Casino, Underworld, Alien Hive), new enemies per faction, mid-bosses.
- More weapons, perk synergies, unlockable operators, hard mode, boss rush.
- Recorded soundtrack (commission or licensed) replacing the synth music.

## Milestone 3 — Retention and release
- Daily seeded run + leaderboards, achievements.
- Steam page early (wishlists), Steam Next Fest demo, desktop build (Electron or Tauri), Steam Deck check.
- Accessibility: remappable controls, reduced flashing, difficulty assists.
- Localisation of the small amount of text.

## Things to decide with the owner later
- Final game name (check Steam and trademark databases; "NEON WARPATH" is a working title).
- Price point and whether to release a free prologue.
